# 登录页面重新设计文档

## 📋 设计概览

登录页面采用现代化的左右分栏布局，左侧为功能性登录表单区域，右侧为品牌展示和特性介绍区域。整体设计遵循"灵机AI助学平台"的品牌视觉规范。

---

## 🎨 布局结构

### 左侧区域（45%宽度）
- **背景**：纯白色 (#FFFFFF)
- **内容**：登录/注册表单
- **Logo水印**：左上角显示品牌Logo（透明度80%）
- **最大宽度**：420px（居中对齐）
- **最小宽度**：500px

### 右侧区域（55%宽度）
- **背景**：蓝色渐变（从深蓝 #1E3A8A 到浅蓝 #93C5FD）
- **网格图案**：半透明白色网格（50px × 50px）
- **内容**：品牌展示 + 特性卡片网格
- **最大宽度**：600px（居中对齐）

## 🎬 动画效果

### Float动画（Logo浮动）
```css
@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-10px); }
}
```
- 持续时间：3秒
- 缓动函数：ease-in-out
- 循环：无限

### Sparkle动画（闪光效果）
```css
@keyframes sparkle {
  0%, 100% { opacity: 0.3; transform: scale(1); }
  50% { opacity: 1; transform: scale(1.2); }
}
```
- 持续时间：2秒
- 缓动函数：ease-in-out
- 循环：无限

## 🔧 技术实现

### 文件结构
```
web/src/pages/login/
├── index.tsx          # 主登录页面组件
├── right-panel.tsx    # 右侧品牌展示组件
└── index.less         # 样式文件
```

### 依赖库
- **React**：组件框架
- **Ant Design**：表单组件（Form, Input, Button, Checkbox）
- **lucide-react**：图标库（Brain, BookOpen, Lightbulb, TrendingUp, Zap, Sparkles）
- **react-i18next**：国际化支持

### 关键特性
- ✅ 磨砂玻璃效果（backdrop-filter: blur(10px)）
- ✅ 平滑过渡动画（transition: all 0.3s ease）
- ✅ 响应式布局（Flexbox + Grid）
- ✅ 无障碍设计（语义化HTML）
- ✅ 中文化界面
