# 助教中心教育化改造设计

日期：2026-06-14

## 背景

当前学生端 `web` 的 `/teaching-assistant` 页面已经具备助教列表、学习进度、会话数、提问数、测验数等基础能力，但整体视觉气质偏企业工作台和 SaaS 仪表盘。对于智能教学辅助系统，学生进入该页面时更需要看到“继续学习什么”“学习进展如何”“如何快速进入 AI 助教和测验”。

本设计将 `/teaching-assistant` 从普通助教列表改造成学生端的学习起点页：**学习中心首页 + AI 助教入口**。

## 目标

1. 让学生进入页面后立刻知道可以继续学习的课程或助教。
2. 让学习进度、课件覆盖、测验记录以更自然的教育语言呈现。
3. 保留现有接口和业务逻辑，优先改造页面结构、文案和视觉风格。
4. 形成后续学生端页面可复用的教育科技视觉样板。

## 非目标

1. 不新增后端接口。
2. 不新增复杂学习任务系统。
3. 不重做整个学生端布局。
4. 不改登录页、知识库页、学习页等其他页面。
5. 不改变现有 `/learning?dialogId=...` 跳转逻辑。

## 页面定位

`/teaching-assistant` 应定位为：

> 我的学习中心：学生查看学习状态、继续课程学习、进入 AI 助教问答和发起个性化测验的入口。

该页面不再强调“管理助教”，而是强调“学生学习”。

## 页面结构

页面由三个主要区域组成：

```text
/teaching-assistant

┌──────────────────────────────────────────────┐
│ 顶部欢迎学习区 WelcomeBanner                  │
│ - 问候语：晚上好，xxx 同学                     │
│ - 页面标题：我的学习中心                       │
│ - 简短说明：继续课程学习、向 AI 助教提问等       │
│ - 推荐继续学习的课程 / 助教                     │
│ - 继续学习按钮                                 │
│ - 连续学习天数、今日会话次数                    │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 今日学习行动区 LearningActionStrip             │
│ - 继续课程学习                                 │
│ - 个性化测验                                   │
│ - 知识掌握                                     │
└──────────────────────────────────────────────┘

┌──────────────────────────────────────────────┐
│ 我的 AI 助教区 AssistantWorkspace              │
```

## 模块设计

### 1. WelcomeBanner

现有 `WelcomeBanner` 保留用户昵称、当前助教、掌握度、连续学习天数、今日会话次数等数据来源，但调整文案与视觉表达。

推荐文案：

- 顶部标签：`智能学习空间`
- 标题：`我的学习中心`
- 说明：`继续今天的课程学习，遇到问题可以随时向 AI 助教提问。`
- 推荐课程标签：`推荐继续学习`
- 课程按钮：`继续学习`
- 进度名称：`知识点掌握`

当没有可用助教时，欢迎区仍然显示，但推荐课程位置显示：

- 标题：`暂无推荐课程`
- 说明：`请等待老师为班级配置课程助教`
- 继续学习按钮隐藏或置为不可点击状态

### 2. LearningActionStrip

新增轻量组件 `LearningActionStrip`，放在欢迎区和助教列表之间。

职责：将学生下一步可做的学习动作显式呈现出来。

第一版包含三张行动卡片：

1. **继续课程学习**
   - 描述：进入最近的课程助教，继续完成问答与课件学习。
   - 点击：进入当前 `currentDialog` 对应的 `/learning?dialogId=...`。
   - 无 `currentDialog` 时置为不可点击状态。

2. **个性化测验**
   - 描述：根据学习记录生成练习，检查薄弱知识点。
   - 第一版可以仅作为引导卡片，不强制新增全局测验弹窗；测验入口仍保留在每个助教卡片上。
   - 如果复用现有 `QuizModal` 成本较低，可使用当前推荐课程的 `dialogId` 打开个性化测验。

3. **知识掌握**
   - 展示当前推荐课程的 `questionProgress` 和 `docProgress`。
   - 文案使用 `知识点掌握` 和 `课件覆盖`。

该组件不依赖新接口，只接收现有页面已经拿到的 `currentDialog`、`currentStats` 和跳转处理函数。

### 3. AssistantWorkspace

该区域由现有 `TeachingAssistantList` 主体承担，职责是展示可用课程助教。

文案调整：

- 区域标签：`AI 助教`
- 标题：`我的 AI 助教`
- 描述：`选择课程助教开始学习、提问或生成练习。`
- 搜索占位：`搜索课程、助教或知识点`

空状态：

- 无助教：`暂时还没有可学习的课程助教，请等待老师为班级配置课程助教。`
- 搜索无结果：`没有找到相关课程或助教，换个课程名、知识点或助教名称试试。`

### 4. TeachingAssistantCard

现有卡片保留数据来源和交互，但改为课程卡片表达。

状态文案：

- 有学习进度：`继续学习`
- 无学习进度：`待开始`

进度文案：

- `题目掌握` 改为 `知识点掌握`
- `文档覆盖` 改为 `课件覆盖`

指标表达：

- `学习会话` 改为 `学习 X 次`
- `提问次数` 改为 `提问 X 个`
- `测验完成` 改为 `测验 X 次`

按钮：

- 主按钮：`继续学习` 或 `开始学习`
- 次按钮：`生成测验`

点击卡片和主按钮仍跳转到 `/learning?dialogId=...`。次按钮继续打开现有 `QuizModal`。

## 视觉风格

采用“温和教育科技风”。目标是适合高校智能教学辅助平台：清晰、轻量、可信，但不企业后台化。

推荐色彩：

```text
背景：#F6F8FC / #F8FAF5
主色：#2563EB 教育蓝
辅助色：#14B8A6 青绿色
提醒色：#F59E0B 暖橙
正文：#1E293B
次级文字：#64748B
边框：#E2E8F0
```

暗色模式：

```text
背景：#0F172A
卡片：#111827 / #1E293B
主色：#60A5FA
辅助色：#2DD4BF
文字：#E5E7EB
```

视觉规则：

1. 减少深蓝 + 金色的企业感。
2. 背景使用柔和浅色渐变，可加入轻微光斑或网格感。
3. 卡片使用课程卡片式布局，圆角柔和但不过度装饰。
4. 图标使用书本、问答、测验、进度等教育语义。
5. 主操作按钮明显，次操作按钮轻量。
6. 明暗主题都必须保证文字对比度和按钮可读性。

## 数据流

现有数据流保持不变：

1. `useFetchChatAppList()` 获取助教列表。
2. `useAllDialogStats()` 获取每个助教的学习统计、连续学习天数、今日会话数。
3. 页面根据第一个助教生成 `currentDialog`。
4. 页面从 `statsMap` 中读取当前助教的 `currentStats`。
5. `WelcomeBanner`、`LearningActionStrip`、`TeachingAssistantCard` 通过 props 接收数据并展示。
6. 跳转统一使用 `navigate('/learning?dialogId=...')`。

不引入新的全局状态，不引入新的请求层。

## 响应式规则

桌面端：

- 欢迎区左右布局。
- 行动区三列卡片。
- 助教卡片自动网格布局。

平板端：

- 欢迎区上下布局。
- 行动区两列或单列。
- 助教卡片根据宽度自动减少列数。

手机端：

- 所有模块单列。
- 搜索框位于标题下方并撑满。
- 主按钮和次按钮撑满。
- 卡片指标可堆叠，避免横向溢出。

## 状态处理

加载态：

- 第一版可继续使用现有 `Spin`。
- 页面结构应尽量稳定，避免 loading 时布局大幅跳动。

无助教：

- 欢迎区仍显示。
- 推荐课程显示无课程提示。
- 行动区相关按钮不可点击或显示待配置状态。
- 助教区显示友好空状态。

搜索无结果：

- 保留搜索词。
- 显示搜索无结果提示。
- 不隐藏欢迎区和行动区。

数据缺失：

- 统计数据缺失时使用 0。
- 文案使用中性提示，不显示异常堆栈或技术错误。

## 测试清单

1. 有助教时，页面展示欢迎区、行动区、助教列表。
2. 无助教时，页面展示欢迎区和友好空状态。
3. 搜索有结果时，列表正确过滤。
4. 搜索无结果时，显示无结果提示。
5. 点击欢迎区继续学习按钮进入 `/learning?dialogId=...`。
6. 点击行动区继续课程学习进入 `/learning?dialogId=...`。
7. 点击助教卡片进入 `/learning?dialogId=...`。
8. 点击助教卡片的生成测验按钮打开现有 `QuizModal`。
9. 浅色模式下文字、按钮、进度条清晰可读。
10. 暗色模式下文字、按钮、进度条清晰可读。
11. 窄屏下模块不溢出，按钮不遮挡，卡片不拥挤。

## 实施建议

第一版按以下顺序实现：

1. 调整 `WelcomeBanner` 的文案、空助教状态和教育化视觉风格。
2. 新增 `LearningActionStrip` 组件。
3. 调整 `TeachingAssistantCard` 的文案、指标表达和课程卡片视觉。
4. 调整 `index.tsx` 页面结构、空状态和搜索文案。
5. 检查浅色、暗色、桌面、移动端表现。

该设计可以在不改变接口和后端逻辑的情况下完成，适合作为学生端教育化 UI 的第一版样板。
