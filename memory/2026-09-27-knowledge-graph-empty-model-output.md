# 知识图谱生成返回空节点诊断

## 现象

管理后台点击“生成知识图谱”返回：`code: 400, message: 模型没有生成有效知识点`。

## 调查结果

- 管理端路由和后端服务均已正常工作，请求进入了知识图谱生成逻辑。
- 当前知识库包含 7 个已完成解析的非视频课件。
- 这些课件中存在 `document_generation` 的 `mindmap` 和 `quiz` 数据，输入数据不是空的。
- 按线上实际代码复现，发送给模型的源数据约 30,747 个字符。
- 线上租户当前使用模型为 `Qwen3-VL-4B-Instruct`，通过 OpenAI 兼容接口调用。
- 模型实际返回长度为 51 的合法 JSON：

```json
{"nodes": [], "edges": [], "questions": []}
```

## 根因

这是模型内容生成结果为空，不是前端、路由、数据库查询或 JSON 解析失败。后端的 `_normalize_graph` 正确拒绝了空节点结果，因此返回了当前提示。

## 后续修复方向

需要调整知识图谱提示和生成策略，明确要求模型至少从已有 `mindmap_nodes` 中提取知识点，并在空结果时进行一次更短、更强约束的重试；必要时增加基于已有思维导图的确定性兜底草稿，避免小模型返回空数组直接失败。
